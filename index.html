Ontario Road Connectivity

About this map
Ontario Road Connectivity is an interactive web map showing road segments classified by cellular service availability: None, LTE, 5G, or Both. The project focuses on how connectivity patterns can be explored across Ontario’s road network at multiple scales.

How to use it
Search for a road by name, optionally filter by jurisdiction, and click a segment to view available road and coverage attributes. The map is intended as both a technical demonstration of web GIS workflow and a practical visualization of transportation-related connectivity.

Data credits
Road data: Ontario Road Network Composite Service, Land Information Ontario.
Cellular coverage data: CRTC geographic service coverage data.

Workflow
Data were cleaned and prepared in ArcGIS Pro, published through ArcGIS Online as a Vector Tile Layer and Feature Layer, and integrated into a Leaflet web application.
